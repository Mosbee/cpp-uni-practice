# C++ University Practice

The C++ learning journey continues...

After completing my initial C++ foundation course (tracked in [`cpp-learning-journey`](https://github.com/Mosbee/cpp-learning-journey)), this repository is dedicated to applying those fundamentals to real academic coursework. Here, I document my solutions, problem-solving approaches, and progress through my university professor's C++ assignments, quizzes, and lab exercises.

## 📚 Repository Structure

- **Assignments/**: Graded coursework and multi-part programming problems.
- **Labs/**: Hands-on practical coding exercises and weekly lab tasks.
- **Quizzes/**: Practice problems and code snippets from class assessments.

## 🛠️ Tools & Environment

- **Language:** C++
- **IDE/Editor:** VS Code
- **Compiler:** MinGW-w64 (GCC)
- **Version Control:** Git & GitHub
